# 2026-10-08 指摘対応付けと自動計画評価の更新

セバスの計画評価で、外部AI指摘の `step` 範囲と達成条件を工程へ対応付ける機能を本番へ反映した。提供差分8ファイルを土台とし、既存コードと統合した。公開リポジトリには未公開だった10月7日のプロジェクト管理画面、ローカルモデル表示、ローカル草案による評価ループも同期する。

## 変更内容

- `1,20`、`1-15`、`5,17-18` などの工程参照を検証し、指摘ごとに候補工程・達成条件・根拠を記録する。不正参照は `invalid_reference`、矛盾や特定不能は `ambiguous` とし、自動反映しない。複数候補を恣意的に単一工程へ縮めない。
- 指摘IDと対応表を修正案へ引き継ぎ、保存済みレビューを使う `remap-preview` / `remap`、人の候補確定 `binding-confirm` を追加した。再対応付けは外部AIを再送しない。
- 外部AIへの依頼文に達成条件IDと工程番号の返却を求める。ただし返答は信頼せず、受信側で再照合する。
- 保存済みレビュー再利用時は実際に呼び出したproviderのみを外部呼出数へ算入する。候補確定前に計画版、GoalContract、packet、レビューを再照合し、同一PJのロックを使う。
